# monke.dev Portfolio

A responsive portfolio of Roblox scripting projects by monke.dev.

## Files

- `index.html` contains the complete website, including styles and video controls.
- `.nojekyll` enables plain HTML hosting through GitHub Pages.

## Publish with GitHub Pages

1. Create a public repository named `monke-dev-portfolio`.
2. Upload `index.html` and `.nojekyll` to the root of its `main` branch.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**, then **main** and **/(root)**. Click **Save**.
5. Wait for GitHub to show the published website link.

For this repository name, the website address will follow the format `https://YOUR-USERNAME.github.io/monke-dev-portfolio/`.

## Updating the website

Replace `index.html` in the repository with the updated portfolio. GitHub Pages publishes changes from the selected branch.

Official setup guide: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
